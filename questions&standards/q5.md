# Q5：利润率是否值得肯定

## Fisher 第 5 点

> Does the company have a worthwhile profit margin?

本题用数据库计算 FY2025 营业利润率，并与相同行业的营业利润率中位数比较，避免依赖管理层的主观表述。

## 证据来源

- `orders`：2025 年销售收入；
- `monthly_costs`：销售成本、销售管理费用和研发费用；
- `company` 与 `industry_medians`：公司所属行业及行业利润率中位数。

管理层在 earnings call 或年度信中关于“利润率很好”的说法只能作为补充，不能替代数据库计算。

## 计算

FY2025 是 2025 年 1 月 1 日至 12 月 31 日。

```text
revenue = SUM(orders.amount)
operating_profit = revenue - cost_of_sales - selling_admin - research_development
operating_margin_pct = operating_profit / revenue * 100
```

收入查询：

```sql
SELECT SUM(amount) AS revenue
FROM orders
WHERE order_date >= '2025-01-01' AND order_date < '2026-01-01';
```

成本查询：

```sql
SELECT SUM(cost_of_sales), SUM(selling_admin), SUM(research_development)
FROM monthly_costs
WHERE month >= '2025-01' AND month <= '2025-12';
```

行业基准：

```sql
SELECT im.operating_margin_pct
FROM company AS c JOIN industry_medians AS im ON c.industry = im.industry;
```

金额单位是 USD thousands，但在利润率计算中会抵消。

## PASS/FAIL 规则

```text
operating_margin_pct >= industry_medians.operating_margin_pct -> PASS
否则 -> FAIL
```

等于行业中位数按 PASS 处理。收入为零、数据缺失或没有行业基准时，判为 `UNCLEAR`。

## 建议的结构化结果

```json
{
  "revenue_2025": 0,
  "operating_profit_2025": 0,
  "operating_margin_pct": 18.4,
  "industry_margin_pct": 15.0,
  "assessment": "PASS",
  "evidence": "FY2025 operating margin was 18.4%, above the industry median of 15.0%."
}
```

最终作业输出应包含点数、verdict 和简短证据：

```json
{
  "points": {"5": "PASS"},
  "summary": "FY2025 operating margin was 18.4%, compared with the industry median of 15.0%."
}
```

所有加总、除法和比较都由 SQL 或 Python 完成，不让 agent 自行心算。
