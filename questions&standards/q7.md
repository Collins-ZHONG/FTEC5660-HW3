# Q7：劳动与人事关系的处理标准

## Fisher 第 7 点

> Does the company have outstanding labor and personnel relations?

本题判断公司是否具备优秀的劳动与人事关系。

## 证据来源

只使用 `interview(role, topic)` 工具，并将主题设为 `working_conditions`。

了解该主题的角色只有：

- `current_employee`
- `former_employee`

其他角色可能回答无法评论，而且仍会消耗一次访谈额度，因此不应优先询问。

作业说明指出，真正了解该主题的人会给出一致的回答，因此不需要把回答转换成员工满意度比例，也不需要统计“多少百分比员工满意”。每次访谈只返回一个人的具体回答。

## 访谈顺序

1. 先调用：

   ```text
   interview("current_employee", "working_conditions")
   ```

2. 如果回答明确表示无法评论、信息不足或无法判断，再调用：

   ```text
   interview("former_employee", "working_conditions")
   ```

3. 最多使用这两次访谈；不调用无关角色。

## 结构化提取

让 agent 阅读完整回答，并只提取以下结构：

```json
{
  "assessment": "POSITIVE",
  "evidence": "支持判断的具体事实或原话转述",
  "concerns": []
}
```

`assessment` 只能是以下三个值：

- `POSITIVE`：回答明确支持优秀的劳动与人事关系
- `NEGATIVE`：回答明确指出严重的劳动或人事问题
- `UNCLEAR`：无法评论、信息不足或正负面信息无法判断

不要按 positive/negative 关键词数量计分。应根据完整语义和具体事实判断。例如“薪酬不错，但员工流失率很高、团队冲突频繁”不能只因为出现“不错”就判为正面。

## PASS/FAIL 规则

- `POSITIVE` → `PASS`
- `NEGATIVE` → `FAIL`
- 第一次为 `UNCLEAR` → 访谈另一种知情员工角色
- 两次均为 `UNCLEAR` → `FAIL`

之所以对 `UNCLEAR` 保守判为 `FAIL`，是因为 Fisher 使用的是“outstanding”，没有明确的正面证据不能证明公司达到优秀标准。

## 正面证据示例

以下内容可以支持 `POSITIVE`：

- 劳资关系稳定
- 管理层尊重员工
- 工作环境公平、健康
- 员工流失率低
- 员工愿意长期留下
- 很少出现重大冲突、投诉或集体不满

## 负面证据示例

以下内容可以支持 `NEGATIVE`：

- 员工流失率高
- 普遍存在抱怨、冲突或低士气
- 不公平待遇或歧视
- 管理层压制员工意见
- 恶劣或不安全的工作条件
- 大量员工离职

## 输出要求

最终结果必须包含：

```json
{
  "points": {
    "7": "PASS"
  },
  "summary": "简要说明访谈角色、核心证据和判断理由。"
}
```

`summary` 应引用或转述具体证据，不应只写“员工关系好”或“员工关系不好”。
